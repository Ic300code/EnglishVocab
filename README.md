# EnglishVocab

EnglishVocab is a website to learn English Vocabulary.
Feel free to download and edit it!

## How to use ?

Edit the ```words.js``` file by adding an element like so:
  ```"[english word]": "[translation in your language]"```

This project is for learning purpose only, and may have many issues.
